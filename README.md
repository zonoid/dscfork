# Stratum Library (Formerly DSCFork)

## Overview

Stratum is a general-purpose library for Joomla! extensions. It was originally a fork of the Dioscouri Library and has been updated to support Joomla 4 and Joomla 5.

**Current Version:** 5.0.0

## Joomla 4/5 Compatibility

This version has undergone initial refactoring for Joomla 4 and Joomla 5 compatibility. This includes:
- Renaming of the library to Stratum.
- Updates to namespaces, class names, and internal references.
- Preliminary adjustments to align with Joomla 4/5 API changes.

**Important Note:** Many areas requiring specific Joomla 4/5 API updates have been marked with `// TODO: J4/5 ...` comments within the code. These areas will require further review and updates by a developer with access to Joomla 4/5 documentation and a development environment to ensure full compatibility and optimal performance.
